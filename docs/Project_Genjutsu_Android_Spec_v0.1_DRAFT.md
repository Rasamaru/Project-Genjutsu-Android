# Project Genjutsu — Android Technical Spec (DRAFT)

**Версия:** Android Spec 0.1 DRAFT  
**Дата:** 9 октября 2026  
**Статус:** проект предложений для согласования; НЕ утверждённое ТЗ.  
**Основание:** решение владельца от 9 октября 2026 — развивать отдельное Android-приложение, начиная с Android 10, ориентируясь на исходники Windows версии 0.2.0-dev.

## 1. Цель

Бесплатное Android-приложение с закрытым исходным кодом, которое по явному разрешению пользователя захватывает экран другого приложения, распознаёт EN/JA/ZH и показывает русский перевод в отдельном оверлее.

Windows-версия не затрагивается. Прямое использование Windows OCR и PySide6 в APK не требуется.

## 2. Платформа и системные разрешения

- Android **10 (API 29)** и новее.
- `MediaProjection`: обязательное системное подтверждение захвата; перед каждой новой сессией на Android 14+.
- `FOREGROUND_SERVICE` с типом `mediaProjection`: видимое уведомление и остановка пользователем.
- `SYSTEM_ALERT_WINDOW`: явное разрешение на оверлей.
- Не обходить античиты, FLAG_SECURE, платформенные ограничения или запросы разрешений.

## 3. MVP / Alpha / Beta

**Прототип 0.1:** выбор EN/JA/ZH → русский; однократное OCR после нажатия плавающей кнопки; локальный перевод после загрузки модели; позиционный перевод с подложкой; явные разрешения; ручная остановка.

**Alpha (после проверки 0.1):** автоматическое определение изменения реплик, стабилизация OCR, ограничение фоновой нагрузки, комфортное чтение, сохранение последнего полноценного текста, корректные позиции при DPI/ориентации, выбор области, проверка моделей на локальное использование.

**Beta:** глоссарии, игровой чат, история по выбору пользователя, профили, онлайн-провайдеры по согласию и естественное восстановление фона там, где это возможно.

**Релиз:** тесты на целевых Android-устройствах, достоверная информация о совместимости и приватности, проверенные лицензии, подписанный APK.

*Разделение по этапам — предложение, а не разрешение автоматически перенести обязательные функции Windows из конечной мобильной версии.*

## 4. Критерии проверки прототипа

1. APK собирается и устанавливается на Android 10+ без Python.
2. Пользователь разрешает/запрещает захват экрана и оверлей через стандартный UI Android.
3. При отказе нет скрытого захвата и приложение не падает.
4. OCR получает координаты EN/JA/ZH; перевод RU показан на экране.
5. Оверлей не блокирует управление игрой, не распознаёт собственный текст, удерживает результат до ручного обновления.
6. Остановка освобождает MediaProjection, VirtualDisplay и OCR/translation resources.
7. Приложение явно сообщает об отсутствии языковой модели, загрузке по Wi-Fi и доступных ограничениях.
8. Нет пользовательских скриншотов в файловой системе, нет скрытой передачи текста сторонним API.

## 5. Приватность и лицензии

ML Kit позволяет локальную обработку OCR и перевода, но SDK отправляет Google метрики своей работы и может загружать модели. Перед публичным распространением владелец должен отдельно утвердить это поведение или выбрать альтернативу, не отправляющую диагностику.

Проверить условия распространения, версий библиотек и возможных обязательств Google ML Kit при коммерчески бесплатном закрытом распространении.

## 6. Открытые технические вопросы

- Как обеспечить стабильную загрузку переводческих моделей на российских устройствах и без сервисов Google?
- Как надёжно не перехватывать касания в Android 12+ на разных прошивках?
- Как исключить опоздавшие OCR и переводы, поддержать вертикальный CJK?
- Как корректно совместить координаты захвата и оверлея при вырезах, multi-window и повороте?
- Как обеспечить «естественную» замену текста на анимированных фонах?

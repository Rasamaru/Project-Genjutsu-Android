# Project Genjutsu Android · 0.1.0 prototype

**Статус:** исходный проект первой Android-итерации. **APK не собран и работа на устройстве не проверена.**

- Исходная Windows-версия: `reference/ProjectGenjutsu_0.2.0-dev.zip` (не изменена).
- Android: minSdk **29 (Android 10)**, Kotlin, Android SDK.
- Проверенные документы: `docs/Project_Genjutsu_Android_Spec_v0.1_DRAFT.md`.
- Не является переносом Windows Python/PySide6 приложения «одной кнопкой».

## Что уже написано

- Запрос SYSTEM_ALERT_WINDOW и системного разрешения на захват экрана по инициативе пользователя.
- Фоновая сессия MediaProjection с видимым уведомлением и остановкой.
- Неблокирующий OCR ML Kit: английский, японский или китайский (выбор вручную), с координатами блоков.
- Перевод ML Kit на русский **на устройстве**; первая загрузка языковой модели **по Wi-Fi**.
- Прозрачный, пропускающий клики оверлей с подложками; отдельная плавающая кнопка `文A` для однократного перевода.
- Перевод группы OCR-блоков собирается и **показывается одним обновлением**, чтобы не заменять целую реплику обрывками при асинхронной обработке.
- Временное скрытие собственного оверлея во время захвата.
- Результат сохраняется на экране до следующего ручного сканирования либо остановки сессии.

**НЕ реализованы:** автоматическое слежение за репликами; стабилизация OCR; режим комфортного чтения в авто; сохранение истории; глоссарии; профили игр; полноценная естественная замена фона; надёжная обработка всех DPI/вырезов/ориентаций; онлайн-провайдеры; готовый релизный APK.

## Сборка на Windows

1. Установи Android Studio и компонент **Android SDK Platform 35** (SDK Manager), а также Android SDK Build-Tools.
2. Распакуй этот ZIP в папку без системных ограничений, например `C:\Dev\ProjectGenjutsuAndroid`.
3. Открой проект в Android Studio и выполни Gradle Sync, затем Build → Build APK(s), **или** запусти `build_android_windows.bat`.
4. BAT при необходимости скачает **официальный Gradle 8.9**. Для первого запуска нужны доступ к Google Maven и Maven Central и Java 17+.
5. Если сборка пройдёт, APK появится как `ProjectGenjutsu-Android-debug.apk`. Это **debug APK**, не предназначенный для публичного релиза.

**Если Android Studio предложит использовать свой Gradle/JDK:** предпочти встроенный JDK 17+ и Gradle 8.9, совместимый с AGP 8.7.3. Gradle Wrapper в архив не включён: исходную wrapper-JAR нельзя получить в текущей офлайн-среде; `build_android_windows.bat` загружает официальный дистрибутив Gradle напрямую.

## Первые шаги на Android-устройстве

1. Установи debug APK и открой Project Genjutsu.
2. Выбери исходный язык (English, 日本語 или 中文).
3. Нажми «Начать». Подтверди запрос уведомлений (Android 13+), разрешение поверх других окон и системное разрешение на захват всего экрана.
4. Подключись к Wi-Fi, если модель перевода ещё не установлена. Дождись уведомления «Офлайн-перевод готов».
5. Открой приложение/игру, нажми `文A` поверх экрана. После обработки увидишь перевод на подложке возле исходных координат.
6. Нажми `文A` снова для обновления. Для прекращения захвата нажми «Остановить» в уведомлении или в приложении.

## Важные ограничения и безопасность

- Приложение **не отправляет изображения и распознанный текст** на сервер разработчика или в облачный переводчик. SDK ML Kit выполняет OCR и перевод на устройстве. Но Google ML Kit **отправляет технические метрики SDK**, может скачивать модели и обновления. Информация об этом есть в главном окне. Для релиза нужно отдельно утвердить применение ML Kit и соответствующую политику приватности.
- На первом запуске модели перевода могут потребовать сеть и Google-сервисы. Доступность загрузки **в России и на устройствах без GMS не проверена**.
- Приложения с защищённым экраном (`FLAG_SECURE`) могут показывать чёрный кадр.
- Начиная с Android 14, каждый новый сеанс MediaProjection требует системного подтверждения.
- Android 12+ ограничивает пропуск кликов сквозь чужие оверлеи, поэтому у фонового текстового окна ограничена непрозрачность до 0.75; поведение нужно проверить на устройстве.
- При повороте экрана сессию требуется запустить заново.
- Проверка координат OCR на устройствах с вырезами, жестовой навигацией и разной плотностью DPI не проводилась.
- История скриншотов и распознанного текста на диск не записывается; логирование пользовательского текста отсутствует.

## Требуемые проверки перед пометкой «работает»

- Сборка Android Studio; запуск на Android 10, 12, 14/15; разрешения; ручной перевод EN→RU, JA→RU, ZH→RU.
- Получение кадра поверх игры без попадания самого Genjutsu; пропуск касаний; сворачивание, переключение игр, сворачивание окна, остановка сессии, поворот, возврат в приложение.
- Повторное нажатие `文A` после 10 минут, отсутствие подвисания, отсутствие лишних вызовов OCR и бесконечного роста RAM.
- Длительное чтение полного перевода; несколько текстовых блоков; потеря интернета после загрузки модели.
